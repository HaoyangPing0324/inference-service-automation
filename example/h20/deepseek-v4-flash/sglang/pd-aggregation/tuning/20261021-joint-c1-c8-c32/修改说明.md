# joint-v1 修改说明

SGLang 0.5.21、DeepSeek-V4-Flash-0731、H20两机1P1D，每角色TP4。本目录保存既有joint-v1的实际改动审阅副本；远端执行位置为本轮candidates/joint-v1/source/，目录内层级与该source保持一致。

| 文件/参数 | 改动与目的 |
|---|---|
| [experiment.toml](experiment.toml) | Prefill chunk4096→8192、静态显存比例0.90→0.88；Decode保持原值。完整并发配置保留，实际候选仅测C1/8/32。 |
| [source/framework/deepseek_v4.py](source/framework/deepseek_v4.py) | 缓存hc_pre的eager闭包与capture模式编译包装；保持阶段选择语义，减少重复创建。 |
| [source/operators/elementwise.py](source/operators/elementwise.py) | 仅对符合条件的BF16二维、宽1024、行4096/8192输入分派到grouped RMSNorm，其他形状/分支保留原实现。 |
| [source/operators/grouped_rmsnorm.py](source/operators/grouped_rmsnorm.py) | 新增4行/CTA的Triton RMSNorm；实验分支不保留隐式Hopper PDL优化，显式enable_pdl=True仍走原实现。 |

源码是完整实际修改文件，不是空占位或整份框架仓库。对应安装包目标分别为sglang.srt.models.deepseek_v4、sgl_kernel.elementwise；grouped_rmsnorm是新增依赖模块。模板中的HTTP响应头与单行RMSNorm功能验证是另一组改动，不能混成本轮联合候选。

既有验证包括CPU数值/阶段选择、GPU数值/out/分派、联合模型加载与真实chat，以及C1/8/32压测；单次联合实验未消融，吞吐小幅提高但C32尾延迟退化，不能证明各层独立或稳定收益。具体指标见[AUTOTUNING_REPORT.md](AUTOTUNING_REPORT.md)，完整命令/确定性补丁仍在[正式报告](../../h20_deepseek-v4-flash_sglang_pd-aggregation.md)中。

本地修改这些文件不会改变服务。用户明确要求应用后，由design比较差异并发布远端隔离新版本，再经调度交execute验证；不自动覆盖当前运行版本。
